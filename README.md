# Proyecto BI - ABP

## 📊 Descripción
Este proyecto corresponde al desarrollo de un dashboard en **Power BI** como parte del proyecto ABP (Bootcamp Análisis de Datos - Talento Digital).  
El objetivo es transformar datos de ventas en información útil para la toma de decisiones, mostrando KPIs, análisis general segmentado, análisis temporal y localidad.

## 🚀 Contenido
- Archivo principal: FranciscoVergaraCorrea_EvaluaciónMódulo8.pbix
- Documentación complementaria: francisco_vergara_correa_eval_mod8_doc_complementario
- Visualizaciones:
  - Dashboard ejecutivo con KPIs y ventas clasificadas
  - Análisis temporal
  - Análisis localidad

## 🛠️ Herramientas utilizadas
- **Power BI Desktop**
- **DAX** para medidas y KPIs
- **Modelado estrella** con tablas de hechos y dimensiones
- **Visualizaciones interactivas** (líneas, columnas, treemap, torta, tabla, mapas, segmentadores)

## 📈 KPIs principales
- Cumplimiento de metas de ventas
- Diferencia entre ventas reales y metas
- Tasa de cantidad de productos con devoluciones
- Tasa de ventas con devoluciones

## 📂 Cómo abrir el proyecto
1. Descarga el archivo `.pbix` desde este repositorio.
2. Ábrelo en **Power BI Desktop**.
3. Explora las diferentes páginas del dashboard para visualizar los análisis.
