# Caso de Estudio: Dashboard de Ventas en Power BI

## 📌 Descripción
Este proyecto consistió en el desarrollo de un dashboard interactivo en Power BI usando dataset base 'SuperStore Sales' obtenido desde la plataforma Kaggle , con el objetivo de visualizar KPIs ventas, análisis temporal y otras clasificaciones de manera clara y ejecutiva. Además, se simularon datos de 'metas' de ventas y 'devoluciones' usando código Python (Pandas, Random) a partir de SuperStore Sales.

## 🎯 Desafío
El principal reto fue la creación de medidas DAX que permitieran obtener conocimiento (métricas confiables) aprovechando un modelo relacional (forma de estrella) integrado por múltiples fuentes de datos (Excel y CSV). La idea era presentar un dashboard ejecutivo que narrara los principales indicadores y visuales de ventas, que llamará a la acción y toma de decisiones informadas.

## 💡 Solución
- Me apoyé con Python para generar datos en formato CSV para complementar análisis.
- Usé **Power Query** para limpieza y transformación de datos.
- Añadí tabla puente y tabla calendario.
- Agregué columnas necesarias para el análisis.
- Modelé relaciones N:M en Power BI siguiendo buenas prácticas de integridad referencial.  
- Construí visualizaciones interactivas con segmentadores y gráficos comparativos.
